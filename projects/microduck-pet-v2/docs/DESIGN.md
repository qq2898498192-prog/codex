# 设计基线与未完成事项

## 需求与设计提议的边界

用户确认取消嘴部、头部俯仰和脚踝舵机；要求屏幕头与小麦克纳姆轮、完整器件布局，以及基于效果图的交互爆炸。用户并未明确同意取消所有腿部运动。V2的固定承力腿/横撑是助手提出的行驶布局假设，不应当作用户已冻结的功能决定。

## 结构方案

头部一体外壳，前框装显示屏，摄像头与ToF分开固定。单个竖直转台负责左右转头，独立轴承承重，执行器只传递转矩。±35°仅演示目标，无机械限位/排线测试。无嘴部、无俯仰轴。

躯干电池下置，主控与配电/实时控制板上置，散热器和检修接口预留。腿内有承力骨架、动力/信号分槽与检修盖。每脚前后两个电机；轮轴载荷经轴承座传到框架，联轴器传扭。

## 重量和轮扭矩

3kg为早期估计；加宽结构后改以3.5kg校核，非称重结果。预算：头颈0.40、躯干电子电池0.80、腿轮架0.85、电机轮0.85、线束紧固件0.25、余量0.35 kg。

假定半径0.03m、5°坡、加速度0.5m/s²、滚阻系数0.05、综合效率0.5、四轮均分：

`T = [m*a + m*g*(sin(theta)+mu*cos(theta))]*r/(4*eta) = 0.0966 N·m/轮`

取2倍为0.193 N·m/轮。横移损失、单轮载荷不均、启动/门槛和持续温升未验证；禁止以堵转扭矩作为连续额定扭矩。130rpm配60mm轮理论空载速度0.408m/s。四轮堵转电流外推合计20A不是连续耗电；必须限流并设计回灌处理。3S满电12.6V，电机与驱动需验证电压/PWM边界。

## 空间方案与冲突

V2横置电机包络使底部总宽294mm、前后156mm、全高373mm；头110×86×92mm。与此前瘦小外观明显不一致。真实电机体积与用户小巧外观要求之间尚未收敛，不能把这个尺寸说成用户已认可。

旧布局模型为XYZ（Z向上）；三维交互试验为Y向上，且几何为独立演示代码，没有严格绑定V2坐标。两者不是同一份CAD。下一步必须统一尺寸参数与装配树。

## 验证情况

- 已检查V2部分电子板、电池和轮电机矩形包络，无正体积相交。
- 排除壳体、骨架、轴承、轮子、转台和线束，不是整机无干涉证明。
- 10秒转头视频为程序生成240帧，H264，1280×900。
- 交互试验通过JS语法及桩环境构建/左侧展开/复位回调检查。当前环境缺少Chromium，未完成真实浏览器WebGL渲染验证。
- 整机爆炸图是AI生成；轮子数量曾出错后改图，最终仍存在电机/轮轴连接方向不可靠的细节。没有与其逐件对应的真实三维模型。

## 按顺序完成的后续工作

1. 冻结实际可购轮子与电机/传动布置，解决294mm底宽问题；不默认继续采用贵的进口电机。
2. 选转头执行器、承重轴承、电池、驱动方案并收集尺寸图。
3. 明确腿部是否只做固定承力或仍需下蹲，重新计算关节/锁止负载。
4. 建统一参数化CAD装配：外壳、骨架、板卡、传动、紧固、线束和维护空间。
5. 验证孔位、厚度、接插件、3D干涉、头转动与线束扫掠、重心及热设计。
6. 从同一CAD导出有名称和层级的GLB，再实现整机与局部爆炸。必须以用户所指整机效果图为外观目标；当前简化模型不算完成。
7. 打样验证后才能交生产文件，尚无可用的最终STL/Gerber。
